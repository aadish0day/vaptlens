# Logo options

Candidate marks, pick one to replace the placeholder. Each is shown as an app-icon tile: `signal` amber `#ffb020` on `canvas` dark `#0a0b0d`, radius 14/64. Single ink, so each works as a flat mark too.

- `option-a-reticle.svg`: the current mark. A scan reticle: ring, pupil, crosshair ticks. Reads as "target / lens". The simplest shape, and survives 16px.
- `option-b-aperture.svg`: camera aperture blades. Reads as "lens" most literally, but is busy below 20px.
- `option-c-lens-chart.svg`: a magnifier with three bars inside. Says "analytics on scans", the Power BI angle. Clearest story, least security-specific.
- `option-d-shield-lens.svg`: a shield with a lens inside. The most security-coded, but shields are common in this category.

Once one is chosen, it replaces the files in Logos and the `Logo` component geometry.
