# Icons

Lucide (ISC license), 24px grid, 2px stroke, round caps and joins. In code use `lucide-react` with `currentColor`; these files are recolored to single ink `#7d8c9b` (`ink-subtle`, dark) for display only.

- Sizes: 16px in buttons, nav and card headers; 14px inside `sm` controls; 12px in badges and tags.
- Mapping: flame = CISA KEV, zap = Zero-day, skull = Ransomware, shield-alert = Exploitable, clock-alert = SLA / EOL, ticket = SEC ticket, grip-vertical = drag handle, network = Network Map, git-compare = Re-Test, kanban = Remediation Board, grid-2x2 = Prioritization Matrix, list-checks = SLA & RACI, server = Asset Inventory, file-text = Executive Report, layout-dashboard = Dashboard.
- No emoji anywhere in the product UI.
