# TierBadge

Asset criticality tier from host profiling.

**Provide:** `tier` (1 | 2 | 3), optional `short` ("Tier 1" only).

- Tier 1 Crown Jewel (a Critical finding, a "prod" hostname, or a database) gets `lens-soft` and three pips; Tier 2 Production two; Tier 3 Dev/Staging one.
- Tiers describe asset value, not risk, so they never use severity colors.
