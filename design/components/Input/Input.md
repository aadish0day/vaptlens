# Input

Text input, by default the slicer's free-text search across hostnames, titles and CVE IDs.

**Provide:** native input props (`value`, `onChange`, `placeholder`…), optional `icon` (defaults to search; `false` hides it).

- Placeholder names what's searched: "Search host, finding or CVE". `surface-200` ground, `border-strong` edge, focus ring on the wrapper.
